# Гитарный сборник

Слова и аккорды для 30 песен. В каждом файле структура: **Куплет / Припев / Бридж**.

## Как открыть

Папка [`songs/`](songs/) — отдельный `.txt` на каждую песню.

Оглавление: [`songs/00-OGLavlenie.txt`](songs/00-OGLavlenie.txt)

## Перегенерация

```bash
python3 generate_txt.py
```

## Тональности (актуальные правки)

| Песня | Тональность |
|---|---|
| В городе лето | Em |
| Кустурица | F#m |
| Ты не верь слезам (Шура) | A#m |
| Лететь (Амега) | Dm |
| Зеленоглазое такси | D#m (оригинал) |
| Салют, Вера | Eb (оригинал) |
